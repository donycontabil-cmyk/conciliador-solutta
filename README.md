# Conciliador Solutta

Conciliador contábil do escritório Solutta: lê os razões de fornecedores e de adiantamento,
mata o que bate dentro de cada razão, sugere as reclassificações e gera o arquivo de ajustes
para importar no sistema contábil.

- Abra no **Google Chrome** ou no **Microsoft Edge** de computador.
- Os dados ficam numa **pasta do computador de quem usa**, escolhida na primeira vez.
  Nada é enviado para este site nem para a internet.
- A empresa de demonstração (SOLUTTA TESTE LTDA) e os fornecedores dela são inventados.
